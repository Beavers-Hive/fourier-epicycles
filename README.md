# フーリエ・エピサイクル — 円の軌跡でお絵かき

キャンバスに描いた絵をフーリエ変換（DFT）で「回転する円の連なり」に分解し、
円の軌跡だけで絵を再現するブラウザアプリ。

**Demo:** https://beavers-hive.github.io/fourier-epicycles/

## 使い方

1. キャンバスにマウスやタッチで絵を描く（複数ストロークOK）
2. 「✓ 完成」を押すと、円の連なりがペン先で絵をなぞるアニメーションが始まる
3. 「円の数」スライダーでフーリエ級数の打ち切り項数を変えられる（増やすほど忠実）

## 複数ストロークの方式

- **方式A: 一筆つなぎ** — 全ストロークを1本の閉路に連結し、ストローク間の移動区間は軌跡を描かずに隠す
- **方式B: 同時に複数ペン** — ストロークごとに独立したフーリエ展開を行い、色分けされた複数のペンが同時に描く

## 仕組み

描いた点列を複素数列 z = x + iy とみなして離散フーリエ変換し、
各係数 c_k を「半径 |c_k|・初期角 arg(c_k)・回転速度 k」の円として振幅順に連結している。

ビルド不要・依存なしの単一HTMLファイル（`index.html`）。
